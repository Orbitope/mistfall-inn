## Accepted licences

**CC0** and **CC BY**. Both permit commercial use and modification, which this
project needs — every asset is re-indexed to a single palette, and that
re-indexing is a modification.

For each CC BY asset, record **title, author, source, licence** in the table above,
note that it was modified, and reproduce the same in the in-game credits.

## Refused, and why

- **CC BY-SA** — ShareAlike attaches to adaptations. Re-indexing to the project
  palette *is* an adaptation, so the result would have to ship under BY-SA and be
  redistributable by anyone. Whether that reaches further than the art itself is
  genuinely contested, and this is a public repo where the licence is checkable.
  Not worth relying on a "probably".
- **CC BY-NC** — bars commercial use.
- **CC BY-ND** — bars derivatives, so the palette pass alone would breach it.
- **No stated licence** — that is all rights reserved, not "probably fine".
  Several otherwise-ideal packs say nothing at all; they are unusable.

## Checking a licence properly

- On itch.io, read the structured **`Asset license`** field in the "More
  information" table, not the description prose. They disagree more often than you
  would expect: `m5x7` has the field set to CC0, while `m6x11` — same author, always
  cited alongside it — has no field at all and only says "free to use with
  attribution".
- On OpenGameArt, read each page's **`License(s):`** field. The CC0 search filter
  returns CC BY-SA results, and badges have been wrong before and corrected only in
  a comment.
- A creator can be mixed. Check every page, not every author.

## Palette

One Lospec palette, all assets re-indexed to it. Record which one here once chosen.
Lospec publishes no licence for palette data, so credit the palette and its author
by name — that is courtesy filling a gap, not a licence being satisfied.
